# Cha-hai 茶海 — В поисках истинного чая

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Технологии
- Next.js 15 + React 19
- shadcn/ui + Magic UI
- Tailwind CSS
- Framer Motion
- TypeScript

## Компоненты Magic UI
- **MagicCard** — карточки товаров с градиентным свечением
- **RippleButton** — все кнопки с ripple эффектом
- **ShimmerButton** — кнопка «Заказать» с мерцанием
- **Highlighter** — подсветка текста в описаниях
- **Lens** — линза для зума фото при наведении
- **Marquee** — бегущие отзывы
- **AnimatedCartButton** — анимированная кнопка корзины
- **InteractiveRating** — звёздный рейтинг товаров
